## Design Context

### Users

Musicians exploring melodic motifs across jazz solos. They need to change similarity thresholds, compare two passages, hear the transcribed lines, and record their interpretation.

### Brand Personality

The user has not specified a brand. The current interface uses a provisional warm, editorial, investigative tone suited to an exploratory music archive.

### Aesthetic Direction

A light paper-and-ink jazz archive with an olive navigation rail, restrained rust accents, editorial serif headings, and compact evidence rows. The interface is responsive and supports reduced motion.

### Design Principles

1. Put the musical relationship and listening workflow ahead of algorithm jargon.
2. Make every similarity control visibly change the result count and ordering.
3. Keep machine rankings distinct from a musician's judgment.
4. Use source provenance and verification states to make evidence trustworthy.
5. Keep the dense explorer usable on narrow screens and by keyboard.
